67 Press Processor

67 Press Processor is a tool for designing printed boxes and planning how they run on a press.

The design tab draws a straight tuck end box dieline from width, depth, height, glue tab, and tuck flap inputs in inches. Solid lines show cuts and dashed lines show folds. An artwork panel can generate or revise box art through the Anthropic API using a key saved only in the browser. The roll tab lays boxes out on the press web with side margin, gap, spit plate, and calibration square, and run animates the roll feeding. Print flat supports Letter, Tabloid, and A4, and download saves the dieline as SVG. Designs save to and load from a JSON file.

Live at 67-press-proccessor.vercel.app
