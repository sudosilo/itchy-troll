Ghost Wing

Ghost Wing is a browser game repo for people who like placing tiles to build a map.

The first version page is a tile placing game with glowing squares to tap, a tile preview, and a Heart Zone solo ranked run with 3 hearts and 15 seconds per tile. Online play is supported.

Latest change. 2026-11-26, v2026.11.26. Created Ghost Wing v1 as a single page tile placing game.
