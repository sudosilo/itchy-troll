Mail-ionaire

Mail-ionaire is a tycoon game for anyone who likes running a small shop that grows into a bigger one. It was cloned from Mill-ionaire.

It keeps its own save and its own score board. The main screen shows a wide format printer and cut plotter, and the floor holds mail machines such as an inserter, a press, a paper roll, a guillotine, a sorter, and a folder.

Live at mail-ionaire.vercel.app.
