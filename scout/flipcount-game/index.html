GRAY

Five rings, 32 slices, read straight down through the window at the top. Watch the GRAY row: only one bit ever changes per step, while plain binary can flip several at once. That is why real rotary encoders on knobs and motors use this pattern.

SOROBAN · BASE TEN
BINARY · BASE TWO

Top frame is a Japanese soroban. A bead pushed against the beam counts. The single bead above the beam is worth 5, each bead below is worth 1. Bottom frame does the same number in binary, one bead per rod, up is 1, down is 0.

The Maya counted in base twenty. A dot is 1, a bar is 5, and the shell means zero. Places stack bottom to top: ones, then twenties, then four hundreds. Hit 20 and a new level appears on top, same carry idea as binary.
