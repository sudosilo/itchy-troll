FLIPCOUNT

FLIPCOUNT is a set of counting toys for people who like numbers and how they are shown.

It has eight tabs: a counter, a bit matching game, an overflow demo, a flip dot display, a gray code wheel, an abacus, a Mayan number page, and a languages tab with spoken words, ancient numerals, and world digit scripts.

Live at flipcount-game.vercel.app
