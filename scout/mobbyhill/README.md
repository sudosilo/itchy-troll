MobbyHill

MobbyHill is a hill climb game for the phone. It is for anyone who wants a quick off road run.

You drive up a wireframe hill from the driver seat and lean by tilting the phone. A run clock times you, flags split the climb, and high scores go to the score hub.

Live at mobbyhill.vercel.app
