EDMIA

EDMIA is a falling block puzzle game where the soundtrack is built from how you play.

Match colors to clear squares while a sweep line moves across the board. Every slide, rotate, drop, and clear plays a note in the song. The track changes sections as you level up. Top scores are saved with three letter initials.

Live at edmia.vercel.app
