EDMIA changelog

2026-10-30, v2026.10.30. Rebuilt the audio engine and gameplay. The fuzz is gone, and the game now has a ghost piece, a next piece preview, held movement, a fall speed tied to the beat, group clears, pause, and keyboard play. Scores now go to a shared world board, with an optional player link and a recent plays feed. A refused link no longer blocks a score. The layout now works in landscape with controls on the sides and a board ten columns wide.

2026-05-21, v2026.05.21. First release. A falling block color match game where clearing squares drives the soundtrack. Includes slide, rotate, drop, and boost controls, song sections that change with level, and a high score table with initials.
