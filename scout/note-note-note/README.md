Note Note Note

Note Note Note is a notebook built on a picture. It is for someone who wants to mark up an image with shaped sticky notes on a phone.

A picture is snapped into colored squares with DMC color and square code toggles. You can brush or box select squares and make them into one note. Tools move, select, rotate, size, and fit the pad. Notes can be searched, deletes can be undone, and a mind map can connect notes. Data saves in the browser, with backup export, import, and erase everything.

Live at note-note-note.vercel.app
