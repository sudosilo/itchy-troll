Vercel Stumbler

Vercel Stumbler is a small tool for anyone who likes poking around the web for live sites hosted on Vercel.

It generates random vercel.app names and opens them in a new tab, and it keeps the ones that are live. It has dictionary and clones tabs for managing word lists and clone hosts, sorts finds into categories, exports and imports backups, and syncs finds to a cloud backend.

Live at stumbler.vercel.app

This app is checked every morning by Control Troll.

Latest change. Hits are now grouped by name across platforms. A cross platform check tests a kept name on every other platform it is not yet kept on.
