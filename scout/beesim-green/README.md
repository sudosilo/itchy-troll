Bee Sim

Bee Sim is a map based bee strategy game that runs in the browser. It is for players who like small tactical simulations.

Bee versus bee mode starts with a chosen map size and side. Mosaic mode starts with a chosen pattern. The map generates terrain with rivers and bush clusters that change movement cost. Defense and advance zones can be placed on the map. A zoom toggle and a menu button work during play.

Live at beesim-green.vercel.app
