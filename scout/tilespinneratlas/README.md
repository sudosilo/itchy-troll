Atlas of Tiles

Atlas of Tiles is a tile rotating puzzle game. It is for players who like calm pattern puzzles.

Tapping a tile rotates it. Closing curves into loops scores matches. Tile traditions pick a regional style that changes the palette and grid shape. Shuffle and reset buttons work, and matches and score show on screen.

Live at tile-spinner.vercel.app
