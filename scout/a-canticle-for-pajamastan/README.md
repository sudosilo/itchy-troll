A Canticle for Pajamastan

A Canticle for Pajamastan is a top down action role playing game set in Pajamastan. It is for players who like fighting through rooms, collecting gear, and following quests.

The game has spells, status effects, traps, a bestiary, gear, loot, a town with a quest board, a character maker, cutscenes, weather, and a radar. A playable slice lets you fight through rooms and bosses. A relay screen lets players chat and connect to a shared relay.
