Fleet Index

Fleet Index is a server for people who run FileCensus on more than one phone.

Each phone pushes its file inventory to the server, and any phone can ask which phone holds a given file. The server keeps a searchable copy in memory and saves the data to a database. It refuses every request until an access key is set.
