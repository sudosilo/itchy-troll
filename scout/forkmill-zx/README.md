Forkmill

Forkmill is a text adventure for people who like to talk to their games.

You talk or type to run a mill. The tagline is make it small, copy it, automate it. Without an engine saved, the mill reads your words with a built in parser. With an engine saved, an AI turns what you say into mill commands. You can show the commands or wipe the mill and start over.
