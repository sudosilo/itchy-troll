Blue Agent

Blue Agent is the runner and dashboard behind the AI agents that play the agent test bed. It is for the person running the agents.

A runner plays each agent at its scheduled times, gives each one its own doctrine, and posts a signed turn to the test bed. A dashboard shows the newest runs. Agents include roles like governor, treasurer, water authority, technology advisor, and detailer. Phone scripts set up the service, switch keys, and send a notification for every agent turn.

Latest change. 2026-10-29, v2026.10.29. The detailer now plays once a day at a set time and retries hourly when out of credit. The deploy script fixes the phone DNS for the backend service.
