Key Decoder

Key Decoder is an educational tool for measuring a key from a photo. It is for people who want to learn how key cuts are read.

You load a photo of a key lying flat next to a coin, and the coin sets the scale. You tap points to place the measurements, pick the key type, and align the blade. The app ranks likely key formats and shows the cut depths. You can download the result as JSON or as a life size SVG profile, and save it to a library. It also has notes on how to identify key fobs.
