Termbeat

Termbeat is a single page app that turns a fake terminal into a music visualizer. It is for anyone who wants a playful screen to run next to a song.

It listens to an audio file or the microphone and makes the terminal react to the sound. You can pick terminal themes such as paper, hacker, Kali, Android, Linux, Windows, and PowerShell. Modes switch between terminal, visualizer, bars, tetris, snake, and pong. Build mode types out source code, and an info panel explains the idea.
