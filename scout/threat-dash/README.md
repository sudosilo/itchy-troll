Threat Dash

Threat Dash is a single page dashboard for the Threat Poller backend. It is for the owner, who wants to see which watched repos need attention.

It shows the output of the poller and lets you manage a watchlist of repos. You can add a repo to the list and remove one from it. It also looks up repo details from GitHub.

This app is checked every morning by Control Troll.
