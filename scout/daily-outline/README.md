Daily Outline

Daily Outline is a simple tracker for anyone who wants one goal per day and a short outline to go with it.

You get one goal per day, with a day strip and a calendar to move between days. Entries save on the device. You can copy the text, download a text file of the day, jump to today, and clear a day. Email link sign in syncs entries to the cloud, and a locked calendar feed is available after sign in.

Live at daily-outline.vercel.app
