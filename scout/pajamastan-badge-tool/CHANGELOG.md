Badge Tool changelog

2026-11-08, v2026.11.08. Added a back side builder for badges with an NFC spot, a QR code, text boxes, seals, and a security look. The Back view can now be opened at any time, and the print switch only controls printing.

2026-11-07, v2026.11.07. Created the badge tool, a page for designing name badges. Added orientation tabs, saved templates with people for each template, a watermark image with background removal, text overlays, and a gradient editor with text angle. The layout editor drags and snaps, with style presets, card seals and patterns, a tilt preview, and more fonts. Email link login saves templates and people to the cloud, and a drawing reader turns a paper mockup into a layout.
