Badge Tool

Badge Tool is a page for designing name badges. It is for anyone in Pajamastan who needs to make badges for a group of people.

You pick portrait or landscape, style the band, background, and text, and save templates with a list of people for each one. A preview shows the badge as you edit.

A Back view lets you build the back of a badge with an NFC spot, a QR code, text, and seals.

Live at pajamastan-badge-tool.vercel.app

Latest change. 2026-11-08, v2026.11.08. Added a back side builder for badges with an NFC spot, a QR code, text boxes, seals, and a security look. The Back view can now be opened at any time, and the print switch only controls printing.
