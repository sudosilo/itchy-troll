Badge Tool

Badge Tool is a page for designing name badges. It is for anyone in Pajamastan who needs to make badges for a group of people.

You pick portrait or landscape, style the band, background, and text, and save templates with a list of people for each one. A preview shows the badge as you edit.

Live at pajamastan-badge-tool.vercel.app

Latest change. 2026-11-07, v2026.11.07. Created the badge tool, a page for designing name badges. Added orientation tabs, saved templates with people for each template, a watermark image with background removal, text overlays, and a gradient editor with text angle. The layout editor drags and snaps, with style presets, card seals and patterns, a tilt preview, and more fonts. Email link login saves templates and people to the cloud, and a drawing reader turns a paper mockup into a layout.
