PDF Text Editor changelog

2026-11-23, v2026.11.23. Added signatures and initials. Draw once, tap a line to auto fit, drag and resize, and the result is flattened into the download. Scanned and photo PDFs can now be signed, and tilted or broken scan lines are followed better. A Text box tool and a bottom Remove bar for placed items were added. Resizing is smoother, with plus and minus buttons that repeat when held.

2026-10-29, v2026.10.29. First release. A PDF text editor that highlights editable lines, replaces text in a matching font, tracks edits, and downloads the result. A deploy was triggered later the same day.
