Stinkin Badges

Stinkin Badges is the backend for the Pajamastan badge tool. It runs as a small Node server.

It reads a photo of a paper badge mockup and returns a layout. It also holds the database setup for saving templates and people.

Latest change. 2026-11-07, v2026.11.07. Created the backend for the badge tool. It reads paper mockups with an AI model and saves to a shared cloud database. Sign in uses email links, and the badge tool is allowed as a return address.
