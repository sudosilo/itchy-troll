NANOVERSE

NANOVERSE is a browser world of simulated cells, built as a single standalone page.

The page loads and draws the world to a canvas with audio.

Live at nanoverse-psi.vercel.app

This app is checked every morning by Control Troll.

Latest change. 2026-11-02, v2026.11.02. Added a train, a big ship, a stadium, and more bridges. The world now renders lighter. The drag and pinch hint text was removed.
