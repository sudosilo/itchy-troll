Rainbow Run changelog

2026-11-07, v2026.11.07. Added a stadium mode with a seating planner, and pictures and video that play on every screen, including YouTube videos and a stunt shared across the crowd. The host signs in, each room gets its own database, and entry kiosks give out one time seat tickets that a seat page can scan with the camera. Added a hype meter that turns the crowd red when phones shake. The microphone now drives the Spectral Engine scenes, and a floor virus spreads between phones that find each other by sound. The menu now has drop down sections.

2026-11-05, v2026.11.05. Added a Screensavers group and a Spectral Engine group to the menu. Coffeekit screensavers now follow the sound playing on the phone. Spectral Engine visualizers run on the wall, and the room loop and beat are passed to the wall scenes.

2026-11-04, v2026.11.04. Created Rainbow Run, a visualizer pedal for the stompbox API. Added a wall host that runs many visualizer scenes across phones lined up side by side, grouped in a menu, with a rain scene, a top down highway scene, and a stars scene. Row size can be set by hand and holds through a reconnect. Added Quad and Nine wall layouts, fit zoom and nudge for each phone, and a panel that fades to a menu button. Added Coffeekit screensavers to the wall.
