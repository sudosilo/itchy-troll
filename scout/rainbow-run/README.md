Rainbow Run

Rainbow Run is a visualizer pedal for the stompbox API, made for people who line phones up side by side as a wall.

A pixel crow flies across phones lined up in a row, and the wall can also run rain, highway, and star scenes. Layouts include Quad and Nine, and each phone can be fitted and nudged. Many scenes are grouped in a menu, including screensavers and Spectral Engine visualizers that follow the room's sound.

Live at rainbow-run-ochre.vercel.app

Latest change. 2026-11-10, v2026.11.10. Added a play a song feature. The song and its chiptune now drive the Spectral Engine and Screensaver scenes the way the microphone does.
