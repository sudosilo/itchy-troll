Spy Hunt

Spy Hunt is a real world hunting game played on phones. It is for a group of friends who want to play spies outdoors.

Everyone enters the same game code and the address of the game server, then picks the red or the blue team. The map shows where the other players are, with a button to recenter and a stop button. A pulse box flashes during the cycle.

Live at spyhunt.vercel.app
