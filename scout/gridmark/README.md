Gridmark

Gridmark is a map tool for keeping track of places you go for work and for yourself.

Save a location as work or personal with a name and notes, using the current position or typed coordinates. The map shows saved marks with a filter for each category. A heatmap view draws where you spend time, and GPS tracking records a point every 10 seconds. All data stays on the device.

Part of the sudosilo project set. Documentation is kept current by the scribe.
