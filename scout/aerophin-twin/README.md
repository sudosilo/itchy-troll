Aerophin Twin

Aerophin Twin is a drawing set for two coffee machines. It is for anyone building or reviewing the designs.

The drawing set view shows twelve sheets for two machines, a motorized column press in inches and a spring press brew head in millimeters. Each part section ends with a bill of materials. The part drawings view shows interactive 3D models that rotate and explode into parts, with buttons to pause, reset the view, and stop rotation. A brew cycle animation shows the piston, knob twist, and drip phases.
