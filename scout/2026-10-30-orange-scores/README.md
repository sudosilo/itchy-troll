Score Hub

Score Hub is a shared score service for the games on this account. It is for players who want one place to see top scores, and for the games that send them.

Games post a score with a three letter tag and an optional link through one small script. The hub page lists top scores and live plays for every game. Scores are checked against limits for each game, and a game can be added by registering it once.
