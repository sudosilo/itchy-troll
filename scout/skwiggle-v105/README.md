Skwiggle

This repo started as the Skwiggle drawing game and now holds the Vercel Stumbler, a single page tool for finding live sites. It is for people who like to explore and draw.

The Skwiggle game is a drawing game where a line never stops, faster thins it and slower fattens it, with many modes, saving, sharing, and minting. The current page is the Vercel Stumbler, which builds site addresses, opens them in a new tab, keeps the ones you like, and syncs them. It has stumble, dictionary, and clones tabs and a platform choice that now includes Netlify.
