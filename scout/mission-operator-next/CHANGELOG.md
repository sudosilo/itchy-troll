2026-10-30, v2026.10.30. Every relay call now has a timeout, so a slow feed fails fast, and relays answer in one shape with a hint instead of a bare error. Feeds that need a server key say so plainly, and the app stops asking for a feed it knows it cannot get. API keys are now read from a key store instead of environment variables. Added labels for screen readers and handoff notes for the project.

2026-10-15, v2026.10.15. Rebuilt as a single page with a light theme and the tabs moved to the top. Brought back the full set of layers, with every feed running through the app's own server and shared caching. Each layer can be switched on or off. The tire pressure section is gone.

2026-03-26, v2026.03.26. First release. A scanner console that uses the device location to list nearby aircraft from live flight data, along with cell towers, Wi-Fi, Bluetooth, ham repeaters, and mesh nodes. Includes a logbook and settings.

2026-10-31, v2026.10.31. Hardened the relays and made the missing keys honest. Every upstream call now has an abort timeout, so a hung feed fails fast instead of holding the request open: aircraft 6s, mesh 9s, Overpass 12s per mirror inside a 20s handler budget, N2YO 8s, weather points 8s and each station observation 5s, WiGLE 8s. The ship relay collects for 4.5s instead of 7s, keeps its early exit at 80 ships, and ships with a maxDuration of 20 in vercel.json. Every relay now answers with the same shape, an error code plus a hint, and never a bare 500; the three keyed relays return a 200 with the missing variable named and a plain-words note on where to get it. The browser call now aborts after 20s, checks the HTTP status, survives a body that is not JSON, always resolves, and clears its busy flag on both the success and failure paths. A global error listener turns a thrown error or a rejected promise into a toast instead of a silent freeze. A group whose layers all report NO KEY is marked dead and no longer polled every cycle; a new RETRY KEYS button in Settings wakes it up after the key is added in Vercel. Settings now lists each missing key with where it comes from, and the top bar shows a KEYS MISSING tag while any are unset. Wi-Fi and Bluetooth points come from a hash of the network id instead of Math.random, so the same find always scores the same. Scans-left now saves when the day rolls over. Satellite status is set even when a satellite layer is switched off. renderPanes returns early on the map tab. Added labels for the scan, recenter and map controls, a description tag, Open Graph and Twitter cards, and an inline SVG favicon.
