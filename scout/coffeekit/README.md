# Screensaver

Audio-reactive browser screensaver. 7 modes (plasma, lines, stars, pipes,
matrix, blob, dvd), mic input, file upload playback.

## Structure
    screensaver/
      index.html   <- the whole app, single file

## Run locally
Open screensaver/index.html in a browser. No build step.

## Deploy
Static site. vercel.json sets outputDirectory: screensaver.

Screensaver

An audio reactive screensaver for a spare screen or a party.

Pick plasma, lines, stars, pipes, matrix, blob, or DVD mode. Turn on the microphone or upload a song and the visuals move with the sound. A clock runs in the corner.

Live at screensaver-musicfx.vercel.app
