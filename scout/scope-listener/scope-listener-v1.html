what this is supposed to do
An oscilloscope for comparing two audio sources in real time, a local file or a YouTube video against the phone mic, showing exactly how far apart they are and whether they are drifting. Version 2 adds a direct feed from Offset Listener, so instead of manually loading and matching a video, this page can ask Offset Listener what song is playing nearby right now and load it already synced.
what's real and tested versus still rough
The scope views, correlation, offset and residual measurement, and the manual file-versus-mic and video-versus-mic comparisons are the original working core of this tool. The Offset Listener auto-sync path is new, it depends on Offset Listener's own location-based sync working correctly first, and hasn't been exercised widely yet.
technologies and services involved
The Web Audio API for capturing and analyzing both channels locally, the YouTube IFrame API for the video path, and Offset Listener's own public sync data, read directly from offset-listener.vercel.app, for the auto-sync path.
the thinking behind it
Offset Listener claims two phones are in sync. This tool is the way to actually see that claim measured against a real microphone instead of taking it on faith.
One tap and it listens, identifies, loads a reference copy, finds the spot, and keeps it locked to the room on its own, logging every step.
