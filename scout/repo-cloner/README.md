Repo Cloner

Repo Cloner is a research tool for people who want a game to reskin and sell. It hunts for open source games with sellable licenses.

It searches GitHub for open source games, checks asset licenses and the file tree, and grades each repo as a reskin base. You can ask Claude for a second opinion and save your picks. The Scans tab combines every scan, ranks games by grade, and can hide risky ones. The license scanner flags famous game names or characters, art taken from another game, and share alike art. You sign in to use it, and each person saves their own keys to their own account.

Live at repo-cloner-khaki.vercel.app
