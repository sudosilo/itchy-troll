Engine Companion

Engine Companion is a control page for a trading engine. It is for the developer who watches and steers the engine from a phone.

A status panel shows the engine heartbeat, position, and ledger from the Railway backend. The engine secret saves in the browser and is required to send commands. Pause, resume, and flatten commands get queued for the engine. Pending commands and recent trades list on the page.

Live at engine-companion.vercel.app

This app is checked every morning by Control Troll.
