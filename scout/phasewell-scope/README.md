Phasewell Scope

Phasewell Scope is a dual channel audio scope in the browser. It is for anyone who wants to compare a song file with what a microphone hears.

It compares a local song file against the microphone. Views switch between overlay, split, X-Y, difference, spectrum, waterfall, radial, and correlation. Offset, residual, and match readouts update live, with align now, auto track, and reset trim. A YouTube video can load as a source. Trigger, auto level, and freeze controls work.

Live at phasewell-scope.vercel.app
