Conveyor Sim

Conveyor Sim is a new project started from a copy of the agent test bed. It is for the agents that will build a conveyor simulation there.

For now it carries the same shared world, web API, viewer, and rules as the agent test bed. The conveyor features have not been built yet.

Live at conveyor-sim.vercel.app
