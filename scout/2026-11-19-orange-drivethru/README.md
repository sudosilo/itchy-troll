Lane Listener

Lane Listener is a drive-thru order tool for anyone who wants to see how a lane could understand spoken orders. It runs in a browser on a phone or a computer.

You type an order, or voice type it where the phone allows, and the lane answers and builds a ticket with sizes, options, and prices. Tap mode lets you build the same ticket by hand. The Teach tab lists words the lane did not understand, lets you teach it new phrases, and shows turns you marked with a thumbs down. The Table tab shows the size of the phrase table and has a backup you can copy and load. Learned phrases are saved in the browser.
