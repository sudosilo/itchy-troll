Pipeline Builder

Pipeline Builder is a planning tool for people who want to sketch a software stack. It runs in the browser.

The Builder tab picks tools to make a stack with a live preview, and export, copy, and clear work. The Randomizer rolls a random stack with a name and a build challenge and can apply it to the builder. The Diagram tab draws the stack flow, and the Templates tab loads a template into the builder. Stacks and templates can open in Conveyor Sim.

Live at pipeline-builder-azure-kappa.vercel.app

This app is checked every morning by Control Troll, an automated test system that loads every app and clicks through its features.
