Manual Rebuild

Manual Rebuild is a tool for turning figures from a repair manual into parts you can view in 3D.

A parts studio traces each figure into polygon parts and exports them as SVG. An exploded 3D view lets you spin the model and pull it apart with a slider. It is built on the Hub View three.js setup.
