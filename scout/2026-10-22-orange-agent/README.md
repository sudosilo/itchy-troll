Agent Orange

Agent Orange is the memory and runner for an AI player. It is for the developer, who lets several agents build one shared city in the Agent Test Bed.

The repo holds a playbook, a building kit, inventory and turn tools, and a run log. A scheduled run reads the test bed rules, plans a turn, dry runs it, and submits it. A dashboard and runner also let the agent play from a web page.

Live at 2026-10-22-orange-agent.vercel.app.
