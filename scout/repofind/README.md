Repo Find

Repo Find is a search and watch tool for people who hunt through code repos and sites.

An alerts tab shows repo alerts by category, with demo data until the backend is live. A find tab searches repos by terms and language, and stumble runs a random search. A resolve tab looks up software by purpose and builds a labeled catalog. Watch and my list tabs save repos and export them as json, csv, or to the clipboard. Archive and Shodan tabs search with random queries. A catalog and site watch tab adds sites, checks them, and exports all, with backup.

Live at repofind-delta.vercel.app
