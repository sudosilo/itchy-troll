Signal Snapshot

Signal Snapshot is the display panel for a market signal watcher. It is for someone who wants to see which price patterns fired and how they scored.

It watches price bars sent from the ticker tracker. Each new bar is checked on the backend against candlestick patterns, RSI, and momentum. The panel has live, graded, and report views. A clear button resets it.

Live at virality-snapshot.vercel.app
