Kitchen Shed Diagram

This is a 3D build diagram for a 14 by 20 kitchen shed, made to plan the layout before building.

Drag to rotate and pinch to zoom. Layer buttons show the shell, loft, water lines, electrical, sinks, work surfaces, refrigeration, restroom, and wall panels on their own. Explode pulls the parts apart, and tapping a part names it.

Part of the sudosilo project set. Documentation is kept current by the scribe.
