Polygon Starfighter

Polygon Starfighter is a browser space game for people who like dogfights in a wireframe look.

You fly one of five ships with lasers that heat up. Modes include Mothership Hunt, Territory, Long haul, and a Hover race with gates and lap times. A Story mode runs a ten mission campaign with briefings and ship unlocks, following the Starwake storyline. Online leaderboards are kept by a small score server in the server folder.
