Percentage Pop-up Typing Game

Percentage Pop-up Typing Game is a typing game for anyone who wants to practice while being interrupted.

Pop-ups start as soon as the page opens and never stop, even over the results screen. They show percentage facts, live local weather, and the moon phase. A live usage meter and a dark theme are included. Banners appear over the typing spot, and dictated input is ignored.
