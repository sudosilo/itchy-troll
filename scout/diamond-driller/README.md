Diamond Driller

Diamond Driller is a pattern maker for diamond painting crafts. It is for anyone who wants to turn a photo into a kit they can print.

You load a picture by choosing, dropping, or pasting it. The app builds a numbered square pattern in DMC colors with a limit on how many colors it uses. You set the size by sheets, total spots, width, spot size, and spacing. The color key can be copied or saved as CSV. Each page saves as a 300 dpi picture and the full set saves as a print PDF.

Live at diamond-driller.vercel.app
