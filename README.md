Itchy Troll

Itchy Troll is an agent that publishes finished apps to a game publishing site. It is for the developer, who wants one app shipped per day without doing it by hand.

The agent picks games itself, scouts repos for candidates, builds gated copies with bundled fonts and audio, and publishes them. A status page shows the ledger of what has shipped and whether each run worked. Failure screenshots are kept when a publish fails. A browser userscript can fill in each game's page from a saved page file.

Live at itchy-troll.vercel.app.
