Itchy Troll

Itchy Troll is an agent that publishes finished apps to a game publishing site. It is for the developer, who wants one app shipped per day without doing it by hand.

The agent picks games itself, scouts repos for candidates, builds gated copies with bundled fonts and audio, and publishes them. A status page shows the ledger of what has shipped and whether each run worked. Failure screenshots are kept when a publish fails.

Live at itchy-troll.vercel.app.
